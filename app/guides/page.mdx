# Guides

The [reference](/emails) covers each endpoint. Guides cover jobs that span
several, where order matters as much as payloads.

## [Migrate a list](/guides/migrate-a-list)

Move an audience off Resend, Mailchimp, Kit or anything else: suppressions
first, contacts in batches, then a careful first send. Includes the five things
that go wrong on import and a working chunked-import script.
