# Audiences

An audience is a list. Contacts, fields, segments and topics all live inside
one.

Subscribers are unlimited on paid plans, because you pay per email sent. The
free plan caps an account at 500; a contact write that would cross it is
`403 plan_limit_reached`.

## The Audience object

```json
{
  "id": "aud_7k2m9x4v0dz1",
  "object": "audience",
  "name": "Product newsletter",
  "contact_counts": {
    "subscribed": 4210,
    "unsubscribed": 130,
    "total": 4402
  },
  "created_at": "2026-01-15T09:30:00.000Z",
  "updated_at": "2026-06-01T14:00:00.000Z"
}
```

`contact_counts` is only on `GET /audiences/{id}`. It costs a count query, so
the list omits it.

## List audiences

<Endpoint method="GET" path="/v1/audiences" />

Newest first, [cursor-paginated](/conventions#pagination).

```bash
curl https://go.day3.app/api/v1/audiences \
  -H "Authorization: Bearer $DAY3_API_KEY"
```

```json
{
  "data": [
    {
      "id": "aud_7k2m9x4v0dz1",
      "object": "audience",
      "name": "Product newsletter",
      "created_at": "2026-01-15T09:30:00.000Z",
      "updated_at": "2026-06-01T14:00:00.000Z"
    }
  ],
  "has_more": false,
  "next_cursor": null
}
```

## Create an audience

<Endpoint method="POST" path="/v1/audiences" />

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | string | Yes | 1 to 100 characters. |

```bash
curl -X POST https://go.day3.app/api/v1/audiences \
  -H "Authorization: Bearer $DAY3_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Product newsletter" }'
```

Returns `201` with the Audience object.

## Retrieve an audience

<Endpoint method="GET" path="/v1/audiences/{audience_id}" />

Includes `contact_counts`: a count per status plus `total`.

## Update an audience

<Endpoint method="PATCH" path="/v1/audiences/{audience_id}" />

`name` is the only thing you can change.

```bash
curl -X PATCH https://go.day3.app/api/v1/audiences/aud_7k2m9x4v0dz1 \
  -H "Authorization: Bearer $DAY3_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Changelog" }'
```

## Delete an audience

<Endpoint method="DELETE" path="/v1/audiences/{audience_id}" />

<Callout type="error">
Deletes **every contact, field, segment and topic inside it**. Irreversible, no
confirmation step. To stop mailing people, set their contacts to `unsubscribed`
instead.
</Callout>

```json
{ "id": "aud_7k2m9x4v0dz1", "deleted": true }
```

[Suppressions](/suppressions) are account-wide and survive.
