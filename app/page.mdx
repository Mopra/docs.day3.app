## Your first request

```bash
curl https://go.day3.app/api/v1/audiences \
  -H "Authorization: Bearer $DAY3_API_KEY"
```

A `200` with a `data` array means you're set up. No key yet? The
[quickstart](/quickstart) gets you from nothing to a delivered email in three
steps.

## Objects

| Object | Id prefix | What it is |
| --- | --- | --- |
| [Email](/emails) | `eml_` | One transactional email. |
| [Audience](/audiences) | `aud_` | A list of contacts. Everything else lives inside one. |
| [Contact](/contacts) | `sub_` | A subscriber. Unique by email within an audience. |
| [Field](/fields) | `fld_` | A registered custom attribute key. |
| [Segment](/segments) | `seg_` | A saved filter, evaluated live. |
| [Topic](/topics) | `top_` | A category a contact can opt out of on its own. |
| [Campaign](/campaigns) | `cmp_` | One email to a whole audience. |
| [Automation](/automations) | `aut_` | A published flow a contact runs through. |
| [Suppression](/suppressions) | `sup_` | An account-wide "never email this address". |

## Set up in the app, not the API

Sending domains, senders and OAuth clients live in the app at
[go.day3.app](https://go.day3.app). Automations are built on the app's canvas
and only enrolled into from code. Verify a sending domain under **Sending**
before you mail real subscribers.
